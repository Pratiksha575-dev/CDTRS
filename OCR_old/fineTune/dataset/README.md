# Dataset Format Guide

This folder contains your handwritten OCR training data.

## Required Structure

`
dataset/
├── images/         ← your handwritten image files go here
├── labels/         ← matching ground-truth text files go here
└── splits/         ← auto-generated by prepare_dataset.py (do not edit)
`

---

## Image Format

Supported extensions: .png, .jpg, .jpeg, .bmp, .tiff

Each image should contain **one line of handwritten text** OR a full page.
Single-line crops work best for recognition quality.

Examples:
`
dataset/images/page001.png
dataset/images/page002.jpg
dataset/images/note_001.png
`

---

## Label Format

For each image, create a **matching .txt file** in dataset/labels/
with the **exact same filename stem** (just different extension).

The .txt file must contain the **ground-truth text** of that image.

- One file = one image's text
- UTF-8 encoded
- Plain text, no JSON or XML

Examples:
`
dataset/labels/page001.txt    ← contains the text shown in page001.png
dataset/labels/page002.txt    ← contains the text shown in page002.jpg
dataset/labels/note_001.txt   ← contains the text shown in note_001.png
`

### Example label file content (page001.txt):
`
The quick brown fox jumps over the lazy dog
`

---

## Adding New Data Later

Simply add more image + label pairs and re-run the preparation:

`ash
# Add new files:
dataset/images/page050.png
dataset/labels/page050.txt

# Then re-run:
python prepare_dataset.py
python train.py
`

The system will automatically discover all images and create new split files.
A new fine-tuned model version will be saved without overwriting the previous one.

---

## Naming Convention (Recommended)

Use consistent numeric naming for easy management:

`
page001.png / page001.txt
page002.png / page002.txt
...
page999.png / page999.txt
`

Or descriptive names:
`
budget_letter_01.png / budget_letter_01.txt
meeting_notes_02.jpg / meeting_notes_02.txt
`

---

## What NOT to put here

- Do NOT put images without a matching label — they will be flagged and skipped
- Do NOT put non-image files in images/
- Do NOT manually edit files in splits/ — they are auto-generated

---

## Quality Tips

- Higher resolution images give better OCR results
- Single-line crops are easier to train on than full pages
- Make sure labels match the image exactly (same text, same spelling)
- Avoid blank/empty label files
